# e-plantShopping — Paradise Nursery

## Project Overview

Paradise Nursery is an online plant shopping application built with React and Redux Toolkit. It provides a simple, user-friendly experience for browsing houseplants and managing a shopping cart.

Customers can explore different categories of plants, view plant information and prices, add plants to their cart, update quantities, and remove items.

## Repository Name

**e-plantShopping**

## Features

- **Welcome Landing Page:** Introduces Paradise Nursery and provides a Get Started button.
- **Plant Collection:** Displays houseplants organized into categories.
- **Add to Cart:** Allows customers to add plants to their shopping cart.
- **Cart Management:** Supports increasing quantities, decreasing quantities, and removing plants.
- **Dynamic Cart Totals:** Calculates item subtotals and the overall cart total.
- **Navigation:** Provides navigation between the home page, plant collection, and shopping cart.
- **Responsive Styling:** Uses CSS to support different screen sizes.

## Installation and Setup

### Prerequisites

Install Node.js and npm before running the project.

### Steps

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Shopping Cart Functionality

The application uses Redux Toolkit to manage cart state.

The cart supports:

- Adding plants to the cart.
- Removing plants from the cart.
- Updating plant quantities.
- Calculating the total quantity of plants.
- Calculating item subtotals and the overall cart total.
